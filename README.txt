STYRKA PWA

Filer:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

Så publicerar du enklast:
1. Ladda upp hela mappen till en HTTPS-webbserver.
2. Öppna adressen i Chrome på Android.
3. Välj Installera app / Lägg till på startskärmen.

Enkla gratisalternativ:
- GitHub Pages
- Netlify
- Cloudflare Pages

Viktigt:
PWA-installation och service worker kräver HTTPS, förutom vid lokal utveckling på localhost.

Träningsdata sparas lokalt i webbläsaren via localStorage.
Använd Exportera för backup om du byter telefon eller rensar webbläsardata.
